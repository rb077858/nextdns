# 🛡️ מנהל NextDNS

אתר סטטי (HTML/CSS/JS טהור, ללא build וללא שרת אפליקטיבי משלכם) לניהול נוח ומעוצב של פרופילי [NextDNS](https://nextdns.io) - בקרת הורים, לוחות זמנים, חסימת/הרשאת אתרים, מכשירים, שכתובי DNS, פרטיות ואבטחה, והחלת הגדרות על כמה פרופילים בבת אחת. מפתח ה-API נשמר אך ורק ב-`localStorage` של הדפדפן - לא נשמר אף פעם בקוד או ב-Git, ולא נשלח לשום מקום מלבד NextDNS (ולפרוקסי השקוף, ראו למטה).

> **⚠️ חשוב - יש לקרוא לפני השימוש:** ל-NextDNS אין תמיכה ב-CORS עבור קריאות שמגיעות מהדפדפן ממקור (origin) חיצוני כמו GitHub Pages - כלומר **קריאה ישירה מהאתר הזה ל-`api.nextdns.io` תיחסם על ידי הדפדפן**, גם עם מפתח תקין (זו מגבלה של NextDNS, לא של האתר). בשביל זה יש בתיקייה `worker/` פונקציית **Cloudflare Worker** זעירה וחינמית (כ-80 שורות קוד, בלי תלויות) שמעבירה בקשות הלאה בלי לשמור כלום - זהו הרכיב ה"שרתי" היחיד הדרוש, והוא עדיין חינמי לחלוטין וללא כרטיס אשראי. ראו הוראות מדויקות בסעיף "🔀 פרוקסי CORS חינמי" למטה.

## ✨ מה אפשר לעשות

- **בקרת הורים**: חסימת קטגוריות (הימורים, פורנוגרפיה, רשתות חברתיות ועוד) ואפליקציות ספציפיות (טיקטוק, יוטיוב, נטפליקס, פורטנייט ועוד עשרות), חיפוש בטוח, מצב מוגבל ב-YouTube, וחסימת עקיפת ההגבלות.
- **לוח זמנים שבועי ("זמן מסך")**: הגדירו לכל יום חלון שעות פנאי שבו אפליקציות מסומנות יהיו מותרות, ומחוצה לו חסומות אוטומטית.
- **רשימות הרשאה/חסימה**: הוספה והסרה של דומיינים ספציפיים, כולל "מצב הרשאה בלבד" (חסימת רוב האינטרנט חוץ ממה שהתרתם במפורש).
- **אבטחה**: הגנות כמו Google Safe Browsing, זיהוי פישינג, Typosquatting, דומיינים חדשים, כרייה נסתרת ועוד, וחסימת סיומות דומיין (TLD).
- **פרטיות**: חסימת מעקב לפי יצרן מכשיר/תוכנה, רשימות חסימה (Blocklists), וחסימת עוקבים מוסווים.
- **מכשירים**: צפייה במכשירים שזוהו בפרופיל, מחרוזות התחברות (DoH/DoT) להוספת מכשיר חדש בקלות.
- **יומן ופעילות**: תמצית האתרים הפעילים ביותר, וניקוי יומן בלחיצה אחת.
- **שכתובי DNS**: הפניית דומיינים פנימיים ברשת הבית.
- **מספר פרופילים**: ניהול, יצירה ומחיקה של כמה פרופילים (למשל פרופיל נפרד לכל ילד).
- **החלת הגדרות על כמה פרופילים**: בחרו אילו קטגוריות הגדרות (בקרת הורים, אבטחה, רשימות ועוד) להעתיק מפרופיל אחד, ולאילו פרופילים להחיל אותן - על כולם או רק על חלק נבחר.

## 🚀 הרצה מקומית

אין תהליך בנייה (build) בכלל - זה HTML/CSS/JS טהור. אפשר פשוט לפתוח את `index.html` בדפדפן, אבל בגלל שהאתר משתמש ב-ES Modules מומלץ להריץ שרת סטטי מקומי פשוט, למשל:

```bash
python3 -m http.server 8080
# ואז גשו ל- http://localhost:8080
```

## 🌐 פרסום ל-GitHub Pages

1. ודאו שהענף `main` מכיל את הקבצים (מיזוג ה-PR שנוצר לענף הזה).
2. בהגדרות המאגר: **Settings → Pages → Build and deployment → Source: GitHub Actions**.
   קיים כבר workflow מוכן ב-`.github/workflows/pages.yml` שיפרסם את האתר אוטומטית עם כל push ל-`main`.
3. לאחר ריצת ה-Action הראשונה תקבלו קישור בסגנון `https://<המשתמש>.github.io/<המאגר>/`.

## 🔀 פרוקסי CORS חינמי (שלב חובה כמעט תמיד)

בלי הפרוקסי הזה, לחיצה על "התחבר" באתר תיכשל עם שגיאת רשת/CORS - זו לא תקלה באתר אלא מגבלה של NextDNS עצמם (ה-API שלהם נבנה לשימוש משרתים/CLI, לא מדפדפנים). ההגדרה לוקחת כ-2 דקות ובחינם לחלוטין:

### דרך א׳ - הדבקה ישירה בדשבורד (הכי פשוט, בלי טרמינל)

1. הירשמו בחינם ל-[dash.cloudflare.com](https://dash.cloudflare.com/sign-up) (לא נדרש כרטיס אשראי).
2. בתפריט הצד: **Workers & Pages → Create → Create Worker**. תנו לו שם (למשל `nextdns-manager-proxy`) ולחצו **Deploy**.
3. לחצו **Edit code**, מחקו את הקוד לדוגמה, והדביקו את כל התוכן של הקובץ [`worker/index.js`](worker/index.js) מהמאגר הזה. לחצו **Deploy** שוב.
4. תקבלו כתובת בסגנון `https://nextdns-manager-proxy.<שם-המשתמש-שלכם>.workers.dev` - זו הכתובת שיש להזין ב"הגדרות התחברות מתקדמות" במסך הכניסה לאתר.

### דרך ב׳ - שורת פקודה (למי שנוח עם CLI)

```bash
cd worker
npx wrangler login    # פעם ראשונה בלבד, פותח דפדפן להתחברות
npx wrangler deploy
```
הפקודה תדפיס את כתובת ה-Worker בסיום.

**למה זה בטוח**: קראו את [`worker/index.js`](worker/index.js) - הוא רק מעביר בקשות הלאה (`fetch`) עם אותה כותרת `X-Api-Key` שקיבל, בלי לשמור, לתעד או לשלוח את המפתח לשום מקום אחר. אתם שולטים לחלוטין בקוד הזה כי הוא בבעלותכם (בחשבון ה-Cloudflare שלכם) ובקוד הפתוח כאן.

## 🔑 איך משיגים מפתח API

היכנסו ל-[my.nextdns.io/account](https://my.nextdns.io/account) וגללו לתחתית העמוד - שם נמצא מפתח ה-API שלכם. הדביקו אותו במסך ההתחברות של האתר.

## ⚠️ מגבלות ידועות של NextDNS (לא של האתר הזה)

- **אין הגבלת "זמן מסך" נפרדת לכל מכשיר** בתוך אותו פרופיל - לוחות הזמנים וההגבלות חלים על **כל** המכשירים המחוברים לפרופיל יחד. הפתרון: ליצור פרופיל נפרד לכל ילד/מכשיר (האתר תומך במספר פרופילים ומקל על כך).
- **"מצב הרשאה בלבד" הוא קירוב**: NextDNS אינו תומך רשמית ב"חסום הכל חוץ ממה שהותר". האתר מיישם זאת על ידי חסימת סיומות הדומיין (TLD) הנפוצות ביותר - אתר עם סיומת נדירה עלול לא להיחסם.
- **לוח הזמנים לשעות פנאי (Recreation Time)** ידוע כלא תמיד יציב ב-API הרשמי של NextDNS (לעיתים מחזיר שגיאה זמנית) - אם השמירה נכשלת, נסו שוב בעוד רגע.
- הוספת "רשימת חסימה" (Blocklist) מוכנה מראש דורשת את מזהה הרשימה מתוך `my.nextdns.io`, מכיוון שה-API אינו חושף קטלוג מלא וחיפוש טקסטואלי.

## 🔒 פרטיות ואבטחה

- האתר עצמו סטטי לחלוטין. הרכיב היחיד שדומה ל"שרת" הוא ה-Worker השקוף בתיקיית `worker/` שאתם מריצים בחשבון Cloudflare החינמי **שלכם** - הוא לא שייך לנו, לא נגיש לנו, ולא שומר/מתעד כלום (ראו את הקוד המלא - כ-80 שורות פשוטות).
- מפתח ה-API נשמר רק במכשיר הנוכחי (`localStorage`). מחיקתו (כפתור "התנתק") מוחקת אותו לצמיתות מהמכשיר.
- מומלץ לגשת לאתר רק דרך HTTPS (כך בדיוק GitHub Pages מגיש את האתר כברירת מחדל).
